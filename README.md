# yaft-python

YaFT (Yet another Feature Toggle) for Python: decorators for functions,
methods and classes, evaluated by the same rules as every other YaFT port and
checked against the shared
[conformance suite](https://github.com/tehw0lf/yaft-conformance).

Work in progress.
